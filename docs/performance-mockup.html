What this mockup demonstrates

Visual style, color palette, and layout primitives are pulled verbatim from screens/PerformanceScreen.tsx. The deltas below are the "$100M polish" the audit identified as missing — none of these are heavy lifts; most are 1-4 hours of work each.

Already shipping (kept)

  • Two-tab toggle (Personal Records / Exercise History) with the cyan-on-black active state
  • Search + Add row in Personal Records tab
  • Time-range pills (7d/30d/90d/All) and category pills
  • Up-to-10 exercise multi-select selector with chip display
  • Per-exercise volume line chart with gridlines and tooltip-on-tap
  • FAB launcher for cross-feature nav (Hitting, Pitching, ArmCare, ForceProfile)
  • Badge taxonomy (Weight / Velocity / Custom / Auto / ✓ Verified)
  • Dark-glass card aesthetic — rgba(255,255,255,0.04) bg + rgba(255,255,255,0.08) border

Mockup-only (gaps the audit found)

  • Cohort summary strip at top of PR tab: ArmScore, Force Composite percentile, days-since-Mocap. Currently siloed to separate screens, invisible from main dashboard
  • e1RM badge on every PR card (Epley: weight × (1 + reps/30)) — data is already in exercise_logs
  • Sparkline trend on every PR card showing 90-day progression
  • Percentile bar vs cohort (uses existing force_plate_percentiles pattern + missing hittrax norms ingestion)
  • Delta chip (↑40 lb in 90d) — derived from athlete_maxes history
  • Last-5-sessions mini-table per exercise card — directly under the chart, no separate modal needed
  • X-axis labels always visible regardless of point count (current LineChart hides them when N>7 at PerformanceScreen.tsx:1948)
  • e1RM pill in exercise card header — instant context for the volume chart
  • ★ PR marker on the chart point and in the sessions table — visual reinforcement of new records

The 5 bugs to fix before this polish lands

From the full audit at docs/PERFORMANCE_LOGGER_AUDIT.md:

Data-corrupting

  • workout_instances.started_at doesn't exist — every resume shows 0 elapsed (WorkoutLoggerScreen.tsx:506,522)
  • checkAndSavePR has no onConflict — duplicate PR rows accumulate (WorkoutLoggerScreen.tsx:769)
  • Stale-closure debounce — Exercise A data saves under Exercise B (WorkoutLoggerScreen.tsx:834)
  • custom_measurements query has no org_id filter — cross-org leak (PerformanceScreen.tsx:265)

Visible but small

  • actual_duration_seconds + actual_distance invisible on CompletedWorkout (CompletedWorkoutScreen.tsx:145)
  • workoutData null-deref crash on stale workout (WorkoutLoggerScreen.tsx:278)
  • No pull-to-refresh / useFocusEffect on PerformanceScreen — stale data after coach updates
  • Athlete notes per-set: save handler exists but TextInput never mounted (exercise-detail-view.tsx:2984-2997 — dead styles)
